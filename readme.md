Boone Group Rides Map
=


This project shows the routes for the group rides sponsored by Boone Bike and touring. It is a helpful tool for picking which ride is right for you, or for mapping out solo rides in the high county.

Data is taken from Strava routes provided by Boone Bike and Touring. Data was exported as gpx files and then converted to GeoJSON files. There are 4 GeoJSON files, one for each of the rides and one for additional scenic points. 

To view information about the routes or the points, hover over them for a tooltip to appear. Zoom into the map to get accurate route information that can help you navigate. 

Group Rides are subject to regular change, especially with the start times and locations.
